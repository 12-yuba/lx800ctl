# LX800 控制器

TCOMAS LX800 水冷屏（**480×480 圆形 LCD**，`VID:PID = 1A2C:151D`）的第三方轻量上位机。

协议来自对官方软件的 **USB/HID 抓包逆向**，非官方产品。软件由 **DeepSeek** 开发，部分功能由 **Gemini** 完成，AI 作品。

---

## 为什么做这个

官方软件能跑，但它把一家产品线（水冷屏 / 风扇毂 / 控制盒 / 键鼠）全塞进一个 exe，还自带 300MB 内置素材和一份 72MB 的 debug 版 OpenCV。

| | 本软件 | 官方软件 | 差距 |
|---|---|---|---|
| 安装包 | **16.7 MB** | 190 MB | 小 91% |
| 解压后体积 | **约 55 MB** | 595 MB（338 个文件） | 小 91% |
| 运行内存 | **约 95 MB**（单进程） | 587 MB（**6 个进程**） | 小 84% |
| 内核驱动 | **0 个** | **5 个**（含已被微软标记的 WinRing0） | — |
| 管理员权限 | 安装、自启**都不需要** | 需要 | — |

实测内存：空闲约 **95 MB**，GIF 推流峰值约 **200 MB**（开启 LHM 温度模式时额外 +80 MB）。

## 功能

### 屏幕显示
- **本地图片 / GIF 实时推流**：自动缩放至 480×480，支持「填满裁剪」与「完整黑边」两种填充模式
- **亮度调节** 0–100
- **开机动画**：免刷 Flash 直接循环播放（推荐，零闪存磨损）；也支持**烧录进屏幕 Flash**（9.5 MB 上限，带 100% 结构校验）
- **待机静态壁纸**：脱机常驻显示单张图片，可一键转码烧录进待机扇区（950 KB 上限）
- **脱机黑屏熄屏**：电脑待机或未运行上位机时自动关闭背光

### 系统监控
- **CPU** 温度 / 占用 / 频率
- **GPU** 温度 / 占用
- **内存** 占用

### 叠加层（Overlay）
- 四种样式：**圆屏简洁 / 轮播切换 / 全信息面板 / 关闭叠加**
- 轮播模式：三行内容逐页全屏轮换，间隔 1–15 秒可调
- 三行可自由选择指标（CPU 温度/负载/频率、GPU 温度/负载、内存、显存等）
- 位置可拖动，缩放 100–300%，面板不透明度可调
- **不想看数值？一键「关闭叠加」**

### CPU 温度来源（三选一）

| 选项 | 原理 | 开销 | 需要管理员 |
|---|---|---|---|
| **系统热区 · 免驱动**（默认） | Windows 性能计数器读 ACPI 热区 | **0** | **不需要** |
| **LHM · 高精度** | LibreHardwareMonitor 读 CPU 核心 Tctl/Tdie | +80 MB（独立子进程） | 需要 |
| 关闭 | — | 0 | — |

LHM 模式走 **PawnIO 签名驱动**，**不含**已被微软标记的 WinRing0。

### 待机水温显示
默认**关闭**。这样可以在未插实体 NTC 探头时，避免屏幕显示 129℃ 异常点阵残留，保证待机画面纯净。
若已接入冷头 2-Pin 测温线，可随时勾选启用。

### 易用性
- **开机自启**（静默到托盘，写 HKCU 注册表，**不需要管理员**）
- **关闭时最小化到托盘**，双击托盘图标恢复窗口
- **单实例保护**：防止两个实例互相抢屏幕；重复启动会把已有窗口唤到前台
- 所有设置自动保存到 `%APPDATA%\LX800Controller\lx800ctl_config.json`

## 下载与安装

到 [Releases](../../releases/latest) 下载 `LX800Controller_Setup_v1.1.0.exe`，双击运行中文安装向导。

- 默认装到 `%LOCALAPPDATA%\Programs\LX800Controller\`，**全程不弹 UAC**
- 安装向导可勾选：创建桌面快捷方式、开机自动启动

**卸载**：「设置 → 应用 → 已安装的应用」找到「LX800 控制器」，或开始菜单里的卸载入口。
卸载时会自动结束正在运行的程序（不留残留文件夹），并询问是否一并删除配置数据。

> ⚠️ 使用前请**完全退出官方软件**（包括右下角托盘图标），否则设备被占用，程序连不上屏幕。

## 已知问题

- 部分台式机主板不暴露 ACPI 热区（或只返回固定假值），此时「系统热区」模式会给出错误读数，程序会自动告警并提示切换到 LHM 模式。
- 目前仅支持 480×480 的 LX800（`PID_151D`）。官方同系列还有其他屏型（640×480 / `PID_151C` 等），未做适配。
